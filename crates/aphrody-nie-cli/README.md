# aphrody-nie-cli

The `nie` native host CLI and in-process command facade for IEVR data inspection, modding, reverse-engineering workflows, Steam depot operations, and the MCP server.

The `host` feature is the default and aggregates native dependencies. `--no-default-features` leaves the library and binary surfaces disabled. Rendering uses the CPU renderer; GPU/WebGPU options are not part of this crate.
