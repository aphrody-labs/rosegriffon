# shenron-re

Moteur de rétro-ingénierie Rust et parseurs des formats DBXV2 et des archives CPK CRIWARE.

## Commandes

Sur vps ou bunos, jamais sur le poste Windows.

```sh
cargo check -p shenron-re
cargo nextest run -p shenron-re
```

Lint du workspace: `cargo lint`. Règles générales: `AGENTS.md` à la racine.
