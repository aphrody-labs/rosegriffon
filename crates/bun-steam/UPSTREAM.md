# bun-steam upstream map

Steam ecosystem projects mirrored under `third_party/steam-ecosystem/<name>` (shallow clones,
pinned in `src.lock.json`, regenerated with `ay lock`). This file records what `bun-steam` can
reuse from each one, and under which license terms. `bun-steam` is Apache-2.0: GPL/LGPL code is
reference only. Read it to understand the behaviour, then reimplement it; never copy it.

## Already a dependency

| Upstream               | Path        | License           | Use                                                                                                                                                                                                                                                                                                                                                   |
| ---------------------- | ----------- | ----------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| landaire/steamroom 0.3 | `steamroom` | MIT OR Apache-2.0 | CM client, PICS, depot keys, manifest decode, CDN chunks. `bun-steam` pins `steamroom`/`steamroom-client` 0.2; the 0.3 CLI exposes `workshop`, `diff`, `local-info` (depot keys from `config.vdf`) and `save-manifest`, whose library code is worth reusing. Upgrade candidate: check `src/depot/session.rs` and `downloader.rs` against the 0.3 API. |

## Installed tools (vps, `~/.local/bin`)

- `DepotDownloader` v3.4.0: built on prd in `mcr.microsoft.com/dotnet/sdk:10.0-alpine`, self-contained linux-x64 single file.
- `steamroom` (steamroom-cli 0.3.0): built on prd in `rust:alpine`, static-pie musl.
- `steamctl` 0.9.5: `uv tool install` from git at commit 274a8db0.

--app 2799860` (public manifest of depot 2799861 is 5864006674348129563, which matches the local
`depotcache`). `DepotDownloader -app 2799860 -manifest-only` resolves AppInfo; content needs a
license. Offline, `steamctl depot info -f` and `steamroom files --manifest-file` read the local
`depotcache/2799861_5864006674348129563.manifest` (1003 files, 61 GB).
