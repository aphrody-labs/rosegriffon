Bonus spécifiques à la plateforme

Suite à vos retours, nous avons revu le système afin que les taux d'obtention de tous les personnages puissent être boostés sur une seule plateforme. (16 avril)

Les personnages rares avec des taux d'obtention supérieurs font une rotation toutes les 2 semaines !

Augmentez les taux d'obtention de tous les personnages sur une plateforme !

Avec l'implémentation des rotations de groupe, il est possible de profiter d'un boost du taux d'obtention pour chaque groupe sur une seule plateforme. Il n'est pas nécessaire d'acheter le jeu sur une autre plateforme pour obtenir un personnage spécifique.

  • Achat sur Switch : 1re à 3e semaine

  • Achat sur Switch : 4e à 5e semaine

Achetez différentes versions du jeu pour activer plusieurs boosts d'un coup !
L'achat du jeu sur différentes plateformes augmentera le nombre de groupes boostés, ce qui vous permettra d'accélérer votre progrès de collection global. * Si vous achetez le jeu sur toutes les plateformes, tous les effets de boost s'appliqueront simultanément.

  • Achat sur PlayStation et Xbox : 1re à 3e semaine

  • Achat sur toutes les plateformes

  • * Il y a une rotation des personnages rares avec des taux d'obtention supérieurs toutes les 2 semaines.
  • * Seule la première rotation, qui suivra la sortie du jeu, durera 3 semaines au lieu de 2.
  • * Si vous souhaitez annuler votre précommande suite à ce changement, veuillez l'annuler via la plateforme de votre choix.
