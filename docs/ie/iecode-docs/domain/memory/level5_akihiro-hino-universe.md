# Akihiro Hino & LEVEL-5 Universe

- Fondateur et PDG : Akihiro Hino (日野 晃博), fondé en octobre 1998.
- Franchises majeures : Inazuma Eleven, Professeur Layton, Yo-kai Watch, Ni no Kuni (collab Ghibli / Joe Hisaishi), Megaton Musashi, Decapolice, Dark Cloud, Dragon Quest VIII & IX.
- Philosophie : Stratégie cross-média totale (jeu vidéo, anime, manga, cinéma, jouets), récit nekketsu et émerveillement enfantin.
- Inazuma Eleven : Byron Love (Aphrodi / 亜風炉 照美), Collège Zeus, techniques célestes (God Knows, Heaven's Time, God Break).
