# Inazuma Eleven & Level-5 Comprehensive Glossary (用語集)

## 主要キャラクター & 選手 (Characters Glossary)

- **Byron Love (亜風炉 照美 / Aphrodi):** 世宇子中学校（Zeus Junior High）のキャプテン。神の領域に達した美しいサッカーを展開する「神（God）」。代表的な必殺技：ゴッドノウズ（God Knows）、ヘブンズタイム（Heaven's Time）、ゴッドブレイク（God Break）。雷門中や韓国代表「ファイヤードラゴン」でも圧倒的な存在感を放つ。
- **Mark Evans (円堂 守 / Endou Mamoru):** 雷門中学校の熱血キャプテン兼ゴールキーパー。必殺技：ゴッドハンド（God Hand）、マジン・ザ・ハンド、正義の鉄拳。
- **Axel Blaze (豪炎寺 修也 / Gouenji Shuuya):** 伝説のエースストライカー。必殺技：ファイアトルネード（Fire Tornado）、爆熱ストーム、グランドファイア。
- **Jude Sharp (鬼道 有人 / Kidou Yuuto):** 天才ゲームメーカー。帝国学園から雷門中へ。必殺技：イナズマブレイク、皇帝ペンギン2号。
- **Unmei Sasanami (笹波 雲明):** 『Victory Road』の主人公。トラウマによりサッカーができないが、優れた戦術眼とマネジメントで南雲原中を率いる。

## レベルファイブ技術用語 & VFS (Level-5 Technology Glossary)

- **LEVEL-5 (レベルファイブ):** 福岡に本社を置くゲーム制作会社。日野晃博が率いる。代表作：『イナズマイレブン』『レイトン教授』『妖怪ウォッチ』『二ノ国』『メガトン級ムサシ』『デカポリス』。
- **G4 Container (.g4md, .g4mg, .g4pkm):** Level-5独自設計の次世代アセットコンテナ形式。
  - `.g4md`: 3Dモデルメタデータおよびマテリアル定義。
  - `.g4mg`: メッシュ幾何構造（Vertices, Indices, Submeshes）。
  - `.g4pkm`: スケルトンアニメーションパッケージ。
- **Nie VFS (Niers Virtual File System):** Inazuma Elevenゲームデータを高速にRAMマウント・解析するための主権的仮想ファイルシステム。
- **Inagle:** Level-5のゲームデータバイナリ（`cfg.bin`）および各種テーブルをパースするTypeScriptエンジン。
- **Inacord:** Rust MonorepoによるInazuma Eleven VR総合プラットフォーム（Desktop/Web/CLI/Blender/MCP）。

## コミュニティ & プラットフォーム (Platform Glossary)

- **Rose Griffon (rg):** フランス語圏最大のInazuma Elevenコミュニティプラットフォーム。
- **Azalee (Azalée):** Rose Griffonが運用する高機能Discordボット。選手検索、必殺技事典（Glossary）、トーナメント管理、RAG検索を提供。
