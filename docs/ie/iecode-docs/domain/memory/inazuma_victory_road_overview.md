# Inazuma Eleven: Victory Road (英雄たちのヴィクトリーロード) — Overview & Gameplay

## 概要とビジョン

『イナズマイレブン 英雄たちのヴィクトリーロード』（Inazuma Eleven: Victory Road）は、レベルファイブ（LEVEL-5）が開発・発売する超次元サッカーRPGの完全新作。日野晃博（Akihiro Hino）が企画・シナリオを手掛け、南雲原中学校の主人公「笹波 雲明（Unmei Sasanami）」と雷門中学校のモンスタープレイヤー「円堂 ハル（Haru Endo）」の激突を描く熱血ドラマ。

## 主なゲームモードとシステム

- **ストーリーモード（Story Mode）:** サッカーを奪われた少年・笹波雲明が、仲間たちと共にサッカーを取り戻す南雲原中学校の物語。
- **クロニクルモード（Chronicle Mode）:** 歴代4500人以上のキャラクターが登場する集大成モード。過去のシリーズの名試合やチームと対戦可能。
- **ヴィクトリーロード・トーナメント（Victory Road Online Tournament）:** オンライン対戦で全国の監督たちと覇を競うシーズン制ランクマッチ。

## 新戦闘システム & マッチエンジン

- **フォーカスバトル（Focus Battles）:** 1対1の駆け引きをリアルタイムに制する選択アクション。左か右か、プレッシャーとドリブルの瞬間的判断。
- **ゾーン（Zone）:** ゴール前の極限攻防。シュート軌道、キーパーの反応、ブロック技の発動。
- **スクランブル（Scramble）:** ルーズボールの競り合いでボタン連打やタイミング入力によるボール奪取。
- **テンションゲージ（Tension Gauge）:** 必殺技の発動に必要なリソース。パスやドリブルの成功で蓄積。

## プラットフォーム & クロスプログレッション

Nintendo Switch、PlayStation 4、PlayStation 5、PC (Steam)、iOS、Android でのクロスプレイおよびクロスセーブに対応。
