# Inazuma Eleven: Victory Road — Patchnote & Version History

## Patchnote Summary & Balance Updates

LEVEL-5による『イナズマイレブン 英雄たちのヴィクトリーロード』ベータテスト体験版および本編のパッチノート（Patchnote）と更新履歴の集約。

### Beta Test Demo Patchnote v1.1.0 (パッチノート v1.1.0)

- **フォーカスバトルのテンポ改善 (Focus Battle Tuning):** 接触時の移行速度を高速化し、試合展開のスムーズさを向上。
- **テンションゲージ消費バランス調整 (Tension Economy):** 必殺技の連続使用に対するペナルティとゲージ回収率の最適化。
- **キーパー城壁ゲージ調整 (Keeper Castle Wall Gauge):** 強力なシュート技に対するキーパーの耐性とブロック技の威力補正を見直し。
- **コマンダーモード操作性改善 (Commander Mode):** タッチ操作およびコントローラー操作時の作戦指示ラグを解消。
- **バグ修正 (Bug Fixes):** 特定のパス連携時に発生していたアニメーションの停止不具合を修正。

### Beta Test Demo Patchnote v1.1.1 (パッチノート v1.1.1)

- **オンライン対戦安定化 (Matchmaking Stability):** ロビー切断率の低下およびP2P通信遅延の補正アルゴリズムを改善。
- **必殺技威力調整 (Hissatsu Technique Balance):** 一部の過剰な威力を誇っていたロングシュート技の威力減衰距離を調整。
- **UI表示修正 (Display & Patchnote Changelog):** 試合終了後のリザルト画面における経験値とドロップアイテムの表示不具合を解消。
