## Method

Dev server: `bun run dev -- -p 3330` failed with "Another next dev server is already running" (PID 43120, port 3311, same checkout, owned by another agent). Proofs were taken against `http://localhost:3311` instead. That server was not stopped. Its `SITE_URL` resolves to `http://localhost:3000`, so canonicals show that origin in dev and `https://rosegriffon.fr` in production.

Probe: `bun var/seo/probe.ts http://localhost:3311 <paths…>` with a Googlebot user agent. Dev streams dynamic metadata into `<body>`, so the probe scans the whole document and drops inline `<svg>` first, because SVG `<title>` elements would otherwise be read as the page title. Lengths are measured after decoding HTML entities.

## Crawl categories: what changed and what remains

- **No canonical (93):** 79 of them are `/feed/status/<id>`, which is already `noindex` (`feed/status/[id]/page.tsx`). A canonical is not needed there. The other 14 are fixed: 12 tweet articles, `/wiki/avatar`, and `/settings` (now noindex).
- **Canonical mismatch (71):** none is a defect. They are all query-filter or pagination variants (`/feed?reseau=`, `/news?category=`, `/sondages?statut=`, `/community?serveur=`, `/achillea/ranked/history?player=`) that point their canonical at the unfiltered list on purpose, plus `/` vs the slash-less origin. Left unchanged. `/achillea/ranked/history?player=` is the one to reconsider if per-player history should be indexed.
- **Noindex:** `/settings`, `/2fa`, `/dashboard`, `/admin/*` are now noindex at layout level. `/auth/*`, `/(auth)/*`, `/profil/*`, `/maintenance`, `/search` and the private `/shop/*` pages already were. `robots.txt` still disallows `/admin/` and `/dashboard/`, which stops crawlers from seeing the meta tag. That is existing policy and was not changed.
- **Titles > 65 (169):** the cause was the wiki layout template on top of page titles that already carry "- Azalée". It is gone. Wiki detail titles fall back to `<name> | Azalée` when the long form would exceed 65. The crawl's 163c for `/wiki/niveau` also included an SVG chart `<title>` that `tools/crawl/crawl.ts` read as part of the page title. That is a crawler artifact: its `title` handler should ignore `svg title`.
- **Descriptions > 160 (36):** the dynamic sources (chara, tweets, polls, news, Achilléa) are clamped at source on a word boundary. Static copies were shortened (`/`, `/a-propos/rejoindre-rg`, `/charte-engagements`, `/notre-equipe`, wiki `niveau`, `cross`, `equipe`, `succes`). Several crawl figures were overstated because the crawler counted `&#x27;` entities as characters. For example, tournament descriptions are 155c, not 170c.
- **h1 missing (25):** fixed on tournaments (8 URLs), player profiles (12 URLs) and `/wiki/avatar` (h1 on the fallback when the catalogue is unreachable; the loaded Atelier already has one). Not changed: `/achillea/clans/create` and `/achillea/tournaments/create`, because they are noindex and their SSR output is the auth-check placeholder. Also not changed: `/settings` for anonymous visitors, because it redirects to `/login` and the logged-in `AccountShell` already renders an h1.
