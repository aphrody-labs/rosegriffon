# Roadmap 2026-2027 : Inazuma Eleven: Victory Road (NIE) Sovereign Engine & Studio

> **Doctrine**: No Human In The Loop (NHITL) | 100% Upstream Bun v1.4.4+ & Rust 2024
> **Ecosystem**: Rose Griffon (`rosegriffon.fr`), Aphrody (`aphrody.com`), Shenron (`dragonballfr.com`)

---

## 1. Vision & Executive Summary

The **NIE** project achieves full sovereign reconstruction of Level-5's "Lives" engine (`nie.exe`) and Inazuma Eleven: Victory Road into a unified, zero-dependency, pure Rust + Bun stack. It spans native desktop workstations (Vulkan/DX12/GPUI), AAA in-browser execution (WebGPU/WASM), high-cadence headless simulation, multimodal RAG dataset ingestion, and competitive ranked online play.

### Phase 1: Core Formats, Headless Simulation, Save Editor & Memory Mapping
- **Status**: **Completed (November 2026)**
- **Deliverables**:
  - `aphrody-nie-formats`: 100% byte-exact parsers for Level-5 formats (`@UTF`, `CPK`, `CRILAYLA`, `G4TX`, `G4MD/G4MG`, `RDBN`, `cfg.bin`).
  - `aphrody-nie-headless`: CLI runner with 5 subcommands (`detect`, `menu`, `match`, `save-edit`, `capture-menus`, `memory-dump`, `pipeline`).
  - `SaveRunner`: Stream XOR cipher, CRC32 checksum recasting, player level/coin manipulation.
  - `MemoryDump`: Raw `.bin` core dumps + structured JSON memory layout matching `nie.exe` PE memory sections.
  - Unified MCP integration: stdio tools `nie_headless_save_editor`, `nie_menu_capture`, `nie_memory_dump`, `nie_filmcraft_timeline`, `nie_headless_pipeline`.

---

### Phase 2: Tri-Tier Rendering & WebGPU/WASM In-Browser AAA Execution
- **Status**: **In Active Development (Late 2026)**
- **Objectives**:
  - **Asset Streaming**: Mount native Level-5 assets into `crates/aphrody-nie-bevy` without glTF conversions using `image_from_g4tx` and `mesh_from_g4md_g4mg`.
  - **WGSL Toon Pipeline**:
    - Stepped threshold diffuse ramp & specular cutoffs.
    - Inverted Hull vertex normal extrusion outlines for anime aesthetics.
    - Bone-projected face shadow masks preventing unnatural nose/eye self-shadowing.
  - **WASM / WebGPU Shell**: Zero-copy snapshot consumption (`NieFrameSnapshot`) via `aphrody-nie-render3d/src/web.rs` and `packages/nie-web`.

---

### Phase 3: Pro Desktop Shell (GPUI-Kit) & Live Memory Inspection
- **Target**: **Q1 2027**
- **Objectives**:
  - Native 120 FPS desktop workstation built with `longbridge/gpui-kit` / `longbridge/nsh`.
  - Dockable multi-pane workspace:
    - High-throughput CPK Archive Explorer with instant decompression.
    - Live memory inspector hooking game process handles (`OpenProcess`, `ReadProcessMemory`).
    - Disassembly & bytecode explorer (Lua 5.2 PUC-Rio opcode inspector via Tree-sitter & `rg-lua`).
    - Standalone fallback mode via `crates/aphrody-nie-editor` (`eframe`/`wgpu` 30).

---

### Phase 4: FilmCraft / Remotion / HyperFrames Cinematic Suite & 3D Character Morphing
- **Target**: **Q2 2027**
- **Objectives**:
  - **3D Character Editor (`aphrody-nie-ocgen`)**:
    - Full morphological tuning: height, shoulder width, muscle volume, head scale, jaw width.
    - Multi-layer palette swaps: skin tones, hair gradients, eye reflections, uniform colorways.
    - Real-time WebGPU preview synchronized with procedural animation rigs.
  - **Cinematic Timeline (`@aphrody/filmcraft` & `@aphrody/remotion`)**:
    - Multi-track timeline: Video, Overlay VFX, Audio Master, Subtitles.
    - Razor cuts, slip edits, SMPTE timecodes (`00:00:00:00`), dynamic camera tracks.
    - Headless frame-by-frame export via `aphrody-nie-video` through asynchronous hardware NVENC (`h264_nvenc`).

---

### Phase 5: Autonomous Capture Pipeline, Steam/Social Ingestion & Multimodal RAG
- **Target**: **Q3 2027**
- **Objectives**:
  - **Zero-Download HTTP Range Streaming (`@aphrody/hyperframes`)**:
    - Remote MP4 header parsing via HTTP Range requests (`bytes=0-131072`) to locate `moov`/`trak` atoms.
    - Sample-accurate on-demand keyframe extraction without downloading full video files.
  - **Telemetry Correlation**:
    - Tick-synchronized `.jsonl` logging (`aphrody-nie-trace`): ball coordinates, camera matrices, player positions.
  - **Vector Search & RAG**:
    - Vision embeddings (SigLIP 768-dim float vectors) generated on NVIDIA RTX 4070 (`sm_89`) via `ring3-agent`.
    - SQLite vector storage (`var/niers.sqlite`) with `sqlite-vec` index for semantic retrieval ("Find all angles of Fire Tornado executed by Axel Blaze").

---

### Phase 6: Full Multiplayer, Ranked Matchmaking & Sovereign Cloud Deployment
- **Target**: **Q4 2027**
- **Objectives**:
  - **Achillea Esports Engine**: Ranked ladder, Colyseus room synchronization, Elo rating, anti-cheat proof verification.
  - **Cross-Platform Identity**: Discord OAuth, Steam Session verification, Rose Griffon Mail JWT.
  - **Sovereign Mesh Network**: WireGuard + MASQUE tunnel uniting OVH FR nodes (`fr1`, `fr2`), Hostinger US egress (`usa`), and Cloudflare R2 edge storage.
  - **Single Artifact Deployments**: Self-contained Bun AOT binaries (`bun build --compile`) deployed via automated systemd units without external runtime dependencies.
