# Retired Rose Griffon apps

These members were retired from the active workspace but are kept here, with
their full history, as reference sources. They are not Bun workspaces and are
not built, checked or published by CI.

| Path | What it was | Retired by |
| --- | --- | --- |
| `achillea-web/` | The original Achilléa front end (Angular 21) | The Achilléa pages of `apps/rg-website` (Next.js), 2026-09-21 |
| `achillea-bot/` | The standalone Achilléa Discord bot (discordx, MikroORM) | The unified API and the `rg-core` gateways of `apps/rg-bot` |

Run either one from its own directory with `bun install` and its package
scripts if you need to rebuild it.
