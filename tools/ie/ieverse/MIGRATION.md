# NIEverse catalogue migration

This package contains the Inazuma Eleven media catalogue, source URLs, navigation/player contracts, and Rust runtime-link metadata copied from `bun-os/packages/ieverse`. It is host-side metadata and utilities; no emulator, WASM, or WebGPU implementation is included.

The upstream package declares `UNLICENSED`; no separate license grant was found, so this migration does not infer one. Source tests are preserved but were not run.
