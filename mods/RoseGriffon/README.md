# Rose Griffon (VRFW mod)

Club pack for Inazuma Eleven: Victory Road, made for the Rose Griffon association (https://rosegriffon.fr).
Loaded by the VR-Framework mod loader (`requires = VRFW>=3.0`), the same as the Inazuma-Eleven-Fantasy mods.

## Sources

The mod uses only two sources:

- **Rose Griffon:** the official themes in `rosegriffon/packages/rg-ui/src/lib/themes.ts` (`THEMES` colours, `THEME_PACKS` title, logo, wallpaper, pet and mode) and the files in `rosegriffon/packages/rg-assets/public`.
- **The real game:** its packs, read through `nie` from your install (kit texture) and the pack inventory (which menu folders exist).

`theme.toml` only picks a Rose Griffon theme (`rg_theme = "roy"`, or `gaelle`, `azalee-light`, `azalee-dark`, `achillea`) and the game-side kit settings. `scripts/theme.ts` imports `themes.ts` directly, builds one HCT palette per Rose Griffon colour, and derives the Material 3 roles. Change the theme in rg-ui, rebuild, and the kit, menu colours, accents and title logo all follow.

## Rules

- Original Rose Griffon artwork only. Never put base-game files (extracted `cfg.bin`, Lua, textures) in this folder or in a release. Ship delta recipes the way the other VRFW mods do.
- Offline only. This mod does not touch the game's online services, Easy Anti-Cheat, or EOS matchmaking. Achillea rankings stay on Achillea's own site and bot, reported from finished matches; they are not injected into the game's netcode.
- Releases follow `mods/README.md`: README, changelog, licence and attribution, supported game build, SHA-256 of every payload, reversible install.

Two install paths: the game data (kit) goes through `nie mod install` from `var/ie-work/rosegriffon-mod`; the VRFW parts (`mod.toml`, `config.toml`, `content/`, `text/`) are read by the VRFW loader from its mods folder, next to the other VRFW mods.

See `INSTALL.md` for the dry run, install and rollback procedure.

## Build

```bash
NIE_GAME_DIR=".../INAZUMA ELEVEN Victory Road" RG_ASSETS=C:/src/rosegriffon/packages/rg-assets/public \
  bash mods/RoseGriffon/scripts/build.sh
```

The build writes the working mod to `var/ie-work/rosegriffon-mod` (gitignored, game-derived) and runs `nie mod validate`. Installing it with `nie mod install` rewrites the game's `cpk_list` and is reversible with `nie mod uninstall`. Only do it offline: Easy Anti-Cheat may flag modified data.
