Règlement

Format officiel · début {{ s.format.startsAt }} · {{ s.format.durationWeeks }} semaines

Phase 1 — Championnat (BO3)
  • Single round-robin : chaque clan affronte les 7 autres une fois ({{ s.meta.matchdays }} journées, {{ s.results.length }} matchs).
  • Rencontre en BO3 — les 3 manches sont toujours jouées (même en cas de 2-0).
  • Égalité 1-1 → 4e match but en or (host = équipe avec un seul host sur les 3). 0-0 → Jugement d'Avantage.
  • Points : {{ s.format.points.winRegulation }} / 0 · but en or {{ s.format.points.winOvertime }} / {{ s.format.points.lossOvertime }}.
  • Départages : diff. de score → head-to-head → tie-break si 3+ équipes.
Phase 2 — Play-offs (BO5)
  • Top {{ s.format.playoffs.teams }} en double élimination (Winner / Loser Bracket).
  • Le 1er choisit son adversaire entre la 3e et la 4e ; le 2e joue le restant.
  • Séries en BO5. Si égalité après 5 manches → 6e (joueur n'ayant pas joué 2×), puis 7e but en or / Jugement d'Avantage.
  • {{ s.format.playoffWeeks }} semaines de play-offs (weeks 8–10).
